# 轉珠修練場 · Combo Dojo

由常闇TOKOYAMi創建。免費轉珠練習工具（中文／English／日本語）：上傳盤面截圖或用隨機盤面自己轉，計 Combo 數和秒數，支援天降、輪盤、荊棘、炸彈、雲、封條、超暗闇、消去不可、操作開始固定、Pattern 集和路線重播。

A free orb-combo practice tool. Upload a board screenshot or use a random board, drag the orbs yourself, and see how many combos you make and how long it takes.

整個網站就是一個 `index.html`，截圖只在瀏覽器內處理，不會上傳。

本工具與任何遊戲公司無關。
